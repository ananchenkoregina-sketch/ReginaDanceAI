# Regina Dance AI — iPad / Cloud v1.1

Эта версия сделана специально для работы с iPad.

## Что изменилось

- не нужен Python на iPad;
- не нужен FFmpeg на iPad;
- FFmpeg устанавливается на сервере через `packages.txt`;
- API-ключ хранится в Streamlit Secrets, а не в GitHub;
- видео можно загружать прямо из «Фото» или «Файлы» на iPad;
- аудио сначала извлекается из видео на сервере, затем распознаётся;
- интерфейс адаптирован под мобильный экран.

## Что умеет

1. Принимает видео тренировки.
2. Извлекает ключевые кадры.
3. Извлекает аудио и при наличии речи делает расшифровку.
4. Анализирует материал через OpenAI Responses API.
5. Возвращает:
   - анализ видео;
   - идеи Reels;
   - монтаж;
   - hooks;
   - текст на экране;
   - подпись;
   - CTA;
   - Stories;
   - что доснять.

## Важно

Эта версия пока НЕ:
- публикует сама в Instagram;
- читает Instagram-статистику;
- монтирует готовый mp4;
- хранит полноценную медиатеку.

Сначала проверяем качество «мозга» бота.

# Как запустить с iPad

## Шаг 1. GitHub

Создай аккаунт GitHub, если его ещё нет:

https://github.com/

Создай новый репозиторий, например:

`regina-dance-ai`

Для первой настройки удобно сделать репозиторий Public.

## Шаг 2. Загрузить файлы

Открой созданный репозиторий.

Нажми:

Add file → Upload files

Распакуй ZIP на iPad и загрузи содержимое проекта.

В корне должны лежать:

- app.py
- requirements.txt
- packages.txt
- .gitignore
- .streamlit/config.toml

Важно: папка `.streamlit` должна сохраниться.

## Шаг 3. Streamlit Community Cloud

Открой:

https://share.streamlit.io/

Нажми:

Continue with GitHub

Разреши Streamlit доступ к GitHub.

## Шаг 4. Создать приложение

Нажми:

Create app

Выбери:

- Repository: твой `regina-dance-ai`
- Branch: `main`
- Main file path: `app.py`

Можно выбрать имя приложения, например:

`regina-dance-ai`

Нажми Deploy.

## Шаг 5. Добавить OpenAI API key

После создания приложения открой:

App → Settings → Secrets

Вставь:

OPENAI_API_KEY = "твой_ключ"

Сохрани.

Никому не отправляй этот ключ и не добавляй его в GitHub.

## Шаг 6. Проверка

Открой ссылку приложения.

Увидишь:

💃 Regina Dance AI

Затем:

1. выбери цель;
2. загрузи видео с iPad;
3. напиши, что хочешь получить;
4. нажми «ПРОАНАЛИЗИРОВАТЬ ВИДЕО»;
5. дождись результата.
